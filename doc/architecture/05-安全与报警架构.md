# 安全与报警架构

## 1. 目标

安全与报警架构负责把故障检测、报警状态、运行模式和命令裁决连接起来，使设备在异常状态下进入可控姿态。

## 2. 模块分工

| 模块 | 职责 |
|------|------|
| alarm registry | 管理报警定义、活跃实例、触发、清除、session journal、重评估，并放锁后发布事件 |
| alarm binding port | 为项目 detector、HAL 或业务逻辑提供统一触发入口 |
| alarm_bridge | 入站端口绑定、会话 journal 开关、可选锁存运动结案 |
| operational mode | 按 blocking / LOCKOUT / 洗后评估裁决命令与模式 |
| command gateway | 命令入站与副作用路由 |
| output hold | 机构输出抑制（急停 DI 或软件锁存）；电机/流体 poll 共用 |

## 3. 等级语义

等级语义以行为属性表达，而非靠"等级序号大小"隐含。三个属性的组合就是等级的
完整定义：

| 等级 | 阻塞开洗 | 进入 LOCKOUT | 记入会话日志 | 现场表现 |
|------|----------|--------------|--------------|----------|
| MINOR | 否 | 否 | 否 | 仅记录，不影响运营 |
| MAJOR | 是 | 否 | 是 | 禁开洗；洗中不中断；洗完仍活跃 → STOPPED |
| CRITICAL | 是 | 是 | 是 | LOCKOUT，立刻停机路径 |

生命周期与等级正交。目录归类只问两句，按顺序答：

1. 条件消失时能否认定结案？须有持续可观察的「还成立」。能 → `FOLLOW_SIGNAL`，组必须 `NONE`。
2. 若不能：同组下一次动作做成且当时条件已是 false，能否结案？能 → `LATCH` 并填该执行机构的组；不能 → `LATCH` 且组 `NONE`，只等复位或恢复流程结案。

恢复起步强制清非安全不是第三档（接受重来，不是证明故障消失）。安全触发不走这条。

| 生命周期 | 条件消失即结案 | 允许复位结案 |
|----------|----------------|--------------|
| `FOLLOW_SIGNAL` | 是 | 否 |
| `LATCH` | 否 | 是 |

运动结案不是第三档：锁存且填了 `reeval_group` 时，同组下一次到位做成且条件已是
false 即删条目。超时、停止、故障、电流停空闲不发完成事件；电流停须项目证明成功后
自行发布。复位是锁存的兜底，与有没有组无关。

两张表的代码基线是 `domain/safety/model/safety_matrix.h`，`alarm_registry` 的全部
等级与策略判定都查这张表，不再各自写 `level >= MAJOR` 这类内联判断。
`tests/domain/test_safety_matrix.c` 按格点逐一断言（3×3 两组共 18 格），并额外校验
「更高等级不得比更低等级宽松」这条单调性不变量——新增等级若插在中间且属性配错，
逐格断言可能仍通过，但单调性会失败。

未知等级取最严格值、未知生命周期不自动结案：漏配置若默认放行，现场表现是"有报警却
照常开洗"或"安全状态被未定义行为解除"，比误停机危险得多。

命令允许矩阵依赖运行模式，不在上面两张表内，而在
`domain/op_mode/operational_mode.c` 的 `k_cmd_matrix`（7 命令 × 8 状态显式列出，
`CONDITIONAL` 表示允许但需再查急停；运营开关等专属条件在命令附加分支检查）。

## 4. 端到端关系

```text
project detector / HAL / CommWatchdog
        ↓
alarm binding
        ↓
alarm registry
        ↓
alarm event bridge → EVT_ALARM_* / EVT_SAFETY_*
        ↓
operational mode / safety_cutout / abort_home / telemetry / cloud
```

## 5. 项目边界

项目侧负责：

- 报警目录和报警编码表。
- detector 采样、极性、去抖和绑定关系；急停报警由确认事件投影，不走 DI 次数滤波。
- 项目安全 IO；CRITICAL 通讯丢失时的 cutout 由等级推导。
- 具体哪些 lifecycle 事件触发哪些重评估分组。

框架侧负责：

- 通用报警生命周期与 session journal。
- 通用姿态边沿（CRITICAL → LOCKOUT）。
- 锁存运动结案桥接机制。
- 与命令网关、运行模式和事件总线的通用衔接。
- 机构输出抑制（`safety_output_hold`）：热路径只置位，收敛在电机 tick / 流体 poll。
