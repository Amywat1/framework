# 落地范围与演进方向

## 1. 当前已落地范围

当前通用框架已落地：

- DDD 分层和 Ports & Adapters 基础结构。
- runtime bootstrap、事件总线、线程注册和周期任务。
- 命令网关、运行模式和副作用路由。
- 方案引擎、表达式、模板展开、profile 查询接口和 JSON loader。
- 报警 registry、安全姿态、detector helper 和 reeval bridge。
- 设备控制通用模式，包括运动、旋转、互锁和流体路径。
- 参数、部署配置、方案加载和 manifest 校验。
- 云端点位模型、上下行 JSON 和变化检测。
- HAL 端口、sim 后端和部分通用 provider。
- Demo smoke 和当前框架单元测试。

## 2. 当前刻意不落地到框架的内容

以下内容属于项目资产，当前不进入通用框架：

- 完整 profile 采集算法和轮廓资产。
- 完整模板库资产。
- 项目级报警编码目录。
- M8 detector/binding 表。
- 完整水路项目拓扑。
- 完整云端物模型表。
- 真机 IO 点位、地址、极性和部署参数。

## 3. 后续可演进方向

后续演进应优先围绕通用抽象，而不是迁入项目表格：

- profile provider 的更多通用查询能力。
- 方案模板的通用 schema 和校验增强。
- 云端上报调度策略抽象。
- HAL provider 的可组合装配能力。
- 设备控制模式的通用安全约束和诊断信息。
- 项目接入 checklist 和 bring-up 验证脚本。

每项演进都应配套模块设计更新和重新生成的单元测试。
