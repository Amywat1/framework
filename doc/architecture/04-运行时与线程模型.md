# 运行时与线程模型

## 1. 运行时职责

运行时负责把框架和项目接入点按固定顺序装配起来，并启动事件分发和周期任务。它不保存项目业务规则，也不直接解释洗车方案或报警目录。

## 2. 启动阶段

启动过程按阶段组织：

```text
register
  └─ wiring 只注册 adapter/provider/loader
configure_storage
  └─ 注入参数/部署配置路径或存储后端参数
load
  └─ 加载 param_store 与 deploy_store
configure
  └─ 下发 HAL、安全和适配器配置
bind
  └─ 绑定 HAL 实例、device ops 和报警目录
validate
  └─ 执行启动前一致性检查
init
  └─ 初始化 HAL、命令、报警、投影、编排器、适配器并注册周期任务
start
  └─ 启动 HAL start、项目运行态和 scheduler 线程
```

项目通过 `wiring` 和 `project_hooks` 接入，不修改 bootstrap 主流程。

## 3. 线程模型

框架线程模型包含：

- 事件分发线程：异步分发领域事件和系统事件。
- 周期任务：按注册周期执行 bridge、watcher、worker 等任务。
  每个任务累计跳拍次数、回调墙钟耗时和唤醒滞后，经 `periodic_task_get_stats()` 读取。
- 急停采集：由项目选择接入方式。框架提供可选的轮询适配器
  （`adapters/inbound/safety/estop_poll_thread.c`，SCHED_FIFO 高优先级）；
  项目若已有自己的采集通路（例如 DI detector 采样后经报警链路发布同样事件），
  则不接入该适配器，避免同一物理输入产生两条并发事件源。
- 项目周期任务：优先在 `project_register_runtime_tasks()` 中登记，由 scheduler 统一启动。
- 项目线程：仅无法纳入 scheduler 的运行态线程放在 `project_start_runtime()`。

领域模块自身尽量不创建线程，而是由 runtime 或 orchestrator 驱动。

## 4. 错误策略

启动失败、事件总线 fatal、安全输出失败等错误必须显式处理。可恢复错误通过返回码和事件传播，不可恢复错误进入 panic 或安全兜底路径。

错误码的处理分类（瞬时可重试 / 持久性失败 / 调用方缺陷 / 接入缺失）见
`common/sw_error.h`，判定用其中的 helper，不要在调用点重新枚举错误码。

### 4.1 启动失败后的进程约束

`bootstrap_run()` 返回非 `SW_OK` 时，**调用方必须终止进程**，不得重试、也不得
继续运行业务逻辑。

启动序列没有回滚路径：失败点之前的副作用全部保留（端口已注册、报警目录已载入、
HAL 可能已初始化、线程可能已登记但未启动）。不提供 teardown 是有意的取舍——
为覆盖任意阶段失败而维护一套对称的反初始化路径，其自身正确性比"失败即退出"
更难保证，而嵌入式设备由进程管理器重启即可回到确定状态。

重复调用的具体后果：`event_bus_init()` 会在 dispatch 线程可能已运行时重置队列与
订阅表；线程登记表会累积重复条目，`scheduler_start_all()` 随后按整表创建线程，
同一任务被启动多次。两者都不会立即报错，而是表现为难以定位的运行期异常。

多数接入错误应在 validate 阶段由 `port_contract_validate()` 拦住并给出完整缺失
清单——此时尚未初始化硬件、也未启动线程，是最干净的失败点。项目应把必需端口
声明写全，使失败尽量落在该阶段而非更晚。

### 4.2 容量上限

事件总线队列、线程表、报警池等容量常量都附有实测依据与余量说明，见
`runtime/event_bus/event_bus_config.h`、`runtime/scheduler/thread_registry.h` 与
`domain/safety/model/alarm_types.h` 的头部注释。水位可通过
`event_bus_get_stats()` 的 `queue_peak_depth` 系列字段在运行期读取；
`tests/runtime/test_event_bus_capacity.c` 按真机密度压测并断言余量。

运行时文档的代码级细节见 `module-design/runtime/Runtime模块设计.md` 和 `module-design/runtime/EventBus模块设计.md`。
