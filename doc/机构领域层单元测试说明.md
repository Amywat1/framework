## 测试架构

### 分层覆盖策略

```
domain/device/mechanism/
├── gantry.c     → test_gantry    37 用例
└── brush.c      → test_brush     33 用例
```

### 底层 MCC 库桩

两个测试均链接 `middleware/mcc/motor_control_core_sim.c`（x86\_64 仿真桩），替代
aarch64 预编译库。仿真桩行为：

| MCC API | 仿真行为 |
|---------|---------|
| `motor_run_continuous` | 立即置 `MOTOR_PHASE_RUNNING` + 记录方向/频率 |
| `motor_move_to` | 同上（忽略 spec） |
| `motor_stop` | 立即置 `MOTOR_PHASE_STOPPED` |
| `motor_home` | 立即置 `STOPPED`，`position=0`，`baseline_trusted=true` |
| `motor_set_speed` | 更新 `target_freq` 和 `dir`，phase 不变 |
| `motor_recover(MODULE_STOP)` | 置 `STOPPED`，清 fault/fault_code |
| `motor_tick` | 空操作 |

测试中注入故障态的方式：直接写 `s_exec.m[0].phase = MOTOR_PHASE_FAULT`（
`motor_executor_t` 结构体对外公开支持静态分配）。

### 测试隔离与 setUp 约定

**两个测试文件共同约定**：

- `setUp()` 只重置 `motor_executor_t`（调 `motor_init`），不调用领域层 init；
- "未初始化保护"用例须在 `main()` 中**排在最前面**运行，确保领域层内部
  `static motor_executor_t *s_exec` 仍为 NULL（C 静态变量上电值）；
- 其余用例在函数体内第一行显式调用 `gantry_init(&s_exec)` /
  `brush_init(&s_exec, &ops, &cfg)`，保证状态完全可重复。

### 构建与运行

```bash
cmake -B build_sim -DBUILD_SIM=ON
cmake --build build_sim -j4
ctest --test-dir build_sim -R 'test_gantry|test_brush' -V
```

## test_brush（刷子机构）— 33 个用例，全部通过

> `brush.c` 管理侧刷与顶刷共享一台变频器的控制逻辑。两刷通过双线圈接触器切换，
> 模块负责"停变频器 → 断旧接触器 → 通新接触器 → 重启变频器"的完整时序，
> 所有过渡由 `brush_tick()` 推进。

### 测试 Mock 设计

```c
static int        s_set_on_calls;
static brush_id_t s_last_set_on_id;
static int        s_set_off_calls;
static brush_id_t s_last_set_off_id;

static sw_err_t mock_set_on(void *ctx, brush_id_t id) {
    s_set_on_calls++;
    s_last_set_on_id = id;
    return SW_OK;
}
static sw_err_t mock_set_off(void *ctx, brush_id_t id) {
    s_set_off_calls++;
    s_last_set_off_id = id;
    return SW_OK;
}
```

接触器延迟均设为 **0ms**（`release_ms=0`，`close_ms=0`），tick 调用可立即推进，
无需 sleep，时序验证不依赖挂钟时间。

### setUp 流程

`init_exec()`（gear\_count=3，gear\_freq={1500, 3500, 4500}）+ 重置 mock 计数器，
不调 `brush_init`。

### 接触器切换状态序列（delay=0ms 时各阶段 tick 次数）

| 场景 | 序列 | tick 次数 |
|------|------|-----------|
| 首次启动（接触器未吸合） | `brush_start` → CONTACTOR\_ON → STARTING → RUNNING | 2 |
| 停止后同刷再启动 | `brush_start` → 直接 STARTING → RUNNING | 1 |
| RUNNING 切换到另一刷 | `brush_start` → STOPPING → CONTACTOR\_OFF → CONTACTOR\_ON → STARTING → RUNNING | 4 |
| IDLE 时接触器在错误位置启动 | `brush_start` → CONTACTOR\_OFF → CONTACTOR\_ON → STARTING → RUNNING | 3 |
